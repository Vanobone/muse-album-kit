# 公開前チェックリスト

公開リポジトリ（仕組みの共有側）へ送る前に、毎回確認する項目です。git は履歴が残るため、混入は「後で消す」では消えません。送る前の確認が唯一の防波堤です。

## チェック項目

- [ ] 実在の人物名・住所・連絡先など、個人を特定する情報が入っていないか
- [ ] エピソード本文などの「実データ」が混ざっていないか（サンプルは架空のペアになっているか）
- [ ] 認証情報・トークン・鍵・パスワードが含まれていないか（ファイルの中身だけでなく、コミット全体を見る）
- [ ] 画像を入れる場合、そのメタデータ（位置情報など）を確認したか
- [ ] 公開側から、プライベート側リポジトリへのリンクや、その存在を匂わせる記述を不用意に貼っていないか
- [ ] ライセンスと帰属の表記が適切か

## もし混入に気づいたら

- 慌てて通常の削除コミットで済ませない。履歴に残り続ける前提で、公開直後ならリポジトリの作り直しも含めて対処を決める
- 混入した情報の性質（認証情報なら失効を先に）に応じて、順序を変える。認証情報が漏れたら、削除より先に無効化する
