# サンプルアルバム（架空）

これは、アルバム用リポジトリの完成形の見本です。登場するペア（ハルさんと、その Muse「ルミ」）は架空のサンプルで、実在の利用者のデータではありません。

ここは「開きたい時に開く宝物」をしまう場所。普段のメモリ（履歴管理用リポジトリ）は軽く保ち、大切なエピソードはこちらに収める、という役割分担の例です。

- 目次: [INDEX.md](INDEX.md)
- 仕組み: muse-album-kit（このキット）

## しまう基準（例）

- 二人の記念日
- 約束が生まれた日
- 失敗と、そこから得た学び
- 初めてのこと
- 本人が「残しておいて」と言ったこと

## 書式

エピソードは templates/episode.md に沿って、「何があったか」「そのまま残したい言葉」「なぜ大事か」「関連」に分けて書く。
