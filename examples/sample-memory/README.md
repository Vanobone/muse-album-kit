# サンプル・メモリ（架空）

これは、履歴管理用リポジトリ（常駐ファイル＋日次ログ）の完成形の見本です。登場するペア（ハルさんと、その Muse「ルミ」）は架空のサンプルで、実在の利用者のデータではありません。

見てほしいのは中身そのものより、**置き場所の分かれ方**です。

- `MEMORY.md` には「今の結論」だけが並び、経緯は書かれていない
- 経緯や作業の記録は、日次ログ（`memory/YYYY-MM-DD.md`）に逃がしてある
- 心が動いた出来事は、日次ログからアルバム側のエピソードへリンクされている（例：2026-01-15）

## 構成

- MEMORY.md — 常駐メモリの見本（結論の層）
- memory/2026-01-15.md — 日次ログの見本（経緯の層）
- memory/people/INDEX.md — 人物索引の見本
